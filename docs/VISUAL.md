> **구현 메모 (2026-10-21)** — 아래 원문과 다르게 한 곳
> - **밤하늘·노을(다크) 한 가지만 쓴다.** OS가 라이트 모드여도 같은 화면 — 사용자 결정. 2.1의 라이트 토큰은 쓰지 않는다.
> - **하늘은 화면 고정이 아니라 페이지에 붙였다.** `position: fixed`면 스크롤 중 코랄 결과 숫자가 화면 아래 노을(#B4405A) 위를 지나가 2.0:1이 된다(9장 체크리스트 1번 위반). 그래서 하늘을 페이지 높이에 붙이고 노을은 맨 아래 400px 띠에만 둬, 그 위엔 출처(본문색 글씨)만 온다. 스케치의 "제목=밤 · 결과=해 질 녘 · 출처=노을" 배치와 같다.
> - **Barlow Condensed는 Google Fonts `@import` 대신 자체 호스팅**(@fontsource 5.3.0 latin 500·600). 설계 문서의 "외부 요청 0"을 지키기 위해. SUIT도 자체 호스팅(가변 woff2 한 파일, 624KB — 분할본이 없음).
> - 결과 숫자 중 **코랄은 손익분기 범위·해 마커·하단 바 숫자에만** 쓰고, 발전량·절감액 표는 본문색으로 둬서 손익분기가 눈에 먼저 들어오게 했다.
> - 설치비 라벨은 보조금을 켜면 "자부담 360만 원"으로 바뀐다.
> - 입력은 5개 — 보조금(⑤, 안 받음/국비만/직접 입력)을 첫 화면에 추가(2026-10-21 사용자 결정). 패널 수 슬라이더 1~100.
> - 시군구 데이터가 전부 있어 8장의 오류 문구는 방어용으로만 들어가 있다.
> - 확인(헤드리스 Chrome): 노을 위 코랄 글씨 0개(계산 근거 접힘·펼침), Barlow `111`·`888` 폭 같음, 320px 가로 스크롤 0·하단 바 동작, 키보드만으로 "N장으로 바꿔 보기"까지, 움직임 줄이기에서 애니메이션 0개, 외부 요청 0.

# 태양광 손익분기 계산기 — 디자인 문서

> 레퍼런스 이미지의 **분위기**(어두운 남색→진홍 그라데이션, 코랄 포인트, 얇은 선, 넓은 여백)만 가져오고, 구성·그림·문구는 가져오지 않는다.
> 시각 요소는 이 문서가 기준이다. solar-roi-spec.md 6.2장의 색(#FAFAF7·앰버)과 겹치는 부분은 이 문서를 따른다.

---

## 0. 레퍼런스에서 가져온 것 / 안 가져온 것

색 계열, 일반적인 스타일, 아이디어는 보통 저작권 보호 대상이 아니고, 구체적인 그림·구성·문구는 보호 대상이 된다는 일반 원칙으로 나눴다. 법률 판단은 아니다.

| 가져온 것 (분위기) | 안 가져온 것 (원본의 표현) |
|---|---|
| 위는 어둡고 아래로 갈수록 붉어지는 세로 그라데이션이라는 색 흐름 | 원본 이미지 자체, shutterstock 워드마크 |
| 코랄 계열 포인트 색 + 채도 낮은 모브 보조색이라는 조합 | 세로 축에 번호 원 10개를 좌우 교차로 배치한 구성 |
| 얇은 선 아이콘이라는 스타일 | 원본 아이콘 그림 10종 |
| 원형 배지라는 일반 UI 요소 | 입체 그라데이션 구(球) 처리 |
| 요소 수가 적고 여백이 넓은 구성 | 전부 대문자 라벨, 원본 문구, 10개 항목의 선택과 순서 |
| 일반적인 웹디자인 원칙 몇 가지 (5장에서 내 방식으로 적용) | — |

색은 원본에서 분위기를 확인하는 용도로만 샘플링했고(위 #1D1D1F → #2A2B3F → #44364E → #C34059, 원 #D75D71), 실제 값은 아래 콘셉트와 대비 기준에 맞게 새로 정했다.

---

## 1. 콘셉트: 해 질 녘 지평선

레퍼런스의 "위는 밤, 아래는 노을" 그라데이션을 태양광 사이트의 주제로 다시 읽는다. **페이지 전체가 하늘이고, 맨 아래가 지평선이다.**

이 은유를 딱 한 곳에서 데이터로 쓴다. 손익분기 그래프에서 **설치비를 지평선(가로선)으로, 누적 절감액을 떠오르는 선으로, 둘이 만나는 지점을 해(코랄 원)로** 그린다. "해가 지평선을 넘는 순간 = 본전 찍는 날"이라 설명 없이도 읽힌다. 이게 이 사이트에서 유일하게 대담한 요소고, 나머지는 전부 조용하게 둔다.

## 3. 글꼴

| 역할 | 글꼴 | 라이선스 | 비고 |
|---|---|---|---|
| 한글 본문·라벨·제목 | SUIT Variable | SIL OFL 1.1 (저장소 LICENSE 확인) | 기본값처럼 쓰이는 Pretendard 대신 선택. 둘 다 OFL이라 바꿔도 됨 |
| 결과 숫자 | Barlow Condensed 500/600 | SIL OFL 1.1 (google/fonts 저장소 OFL.txt 확인) | **tnum 지원 확인함** (fontTools로 GSUB 기능 목록 조회) |

레퍼런스의 좁고 각진 대문자 느낌은 **대문자가 아니라 좁은 숫자체**로 옮긴다. 이유는 세 가지야. 한글에는 대소문자가 없고, 단위 기호는 대소문자가 의미라 kWh를 KWH로 쓰면 틀린 표기가 되고, 전부 대문자 라벨은 흔한 템플릿 티가 난다.

```css
@import url('https://fonts.googleapis.com/css2?family=Barlow+Condensed:wght@500;600&display=swap');
/* SUIT Variable은 공식 저장소(github.com/sun-typeface/SUIT)의 웹폰트 안내대로 불러오거나 자체 호스팅 */

body { font-family: "SUIT Variable", "Apple SD Gothic Neo", "Malgun Gothic", sans-serif; }
.num {
  font-family: "Barlow Condensed", "SUIT Variable", sans-serif;  /* '원', '만' 같은 한글은 SUIT로 자동 대체 */
  font-weight: 600;
  font-variant-numeric: tabular-nums;   /* 숫자 바뀔 때 자리 흔들림 방지 */
}
.num .unit { font-size: 0.55em; font-weight: 500; color: var(--text-2); margin-left: 0.15em; }
```

### 크기 단계 (모바일 / 데스크톱, px)

| 용도 | 크기 | 굵기 |
|---|---|---|
| 손익분기 범위 숫자 | 40 / 48 | Barlow 600 |
| 발전량·절감액 값 | 26 / 28 | Barlow 600 |
| 페이지 제목 | 24 / 28 | SUIT 700 |
| 섹션 제목 | 18 / 20 | SUIT 650 |
| 본문·입력값 | 16 | SUIT 450 |
| 라벨·보조글 | 14 | SUIT 500, `--text-2` |
| 출처·각주 | 12 | SUIT 450, `--text-2` |

라벨은 문장형 한글 그대로 쓰고 자간을 벌리지 않는다. 본문 줄 길이는 한 줄 40자 안팎(최대 폭 640px 컬럼).

## 4. 레이아웃

단일 컬럼, 최대 폭 640px, 텍스트는 왼쪽 정렬, 숫자 열은 오른쪽 정렬(자릿수 비교가 쉽게).

```
┌────────────────────────────────┐ ← 밤
│ 우리 집에 태양광 달면             │  제목
│ 몇 년이면 본전일까                │
│ 위치랑 전기요금만 넣으면 돼요       │  보조글
│                                │
│ ┌──── 입력 패널 (surface) ────┐  │
│ │ ① 위치      [서울 중구    ] │  │  번호 배지: 입력 순서라는
│ │ ② 패널 수   ──●───── 7장   │  │  실제 순서가 있어서 사용
│ │ ③ 1장 가격  [750,000] 원   │  │
│ │ ④ 전기요금  [71,500] 원/월  │  │
│ │ ▸ 지붕 방향·그늘  모름 / 모름 │  │
│ └────────────────────────────┘  │
│                                │ ← 해 질 녘
│            발전량      절감액     │  결과는 카드 없이
│ 하루       7.5kWh     1,600원   │  하늘 위에 바로
│ 한 달      228kWh    4.9만 원   │
│ 1년      2,730kWh     59만 원   │
│                                │
│   ╭ 누적 절감 ─────●── 해 ───   │  지평선 차트 (1장)
│ ──┼──────────────설치비(지평선)── │
│   약 7~12년이면 본전             │
│                                │
│ ⚠ 잉여 경고 (있을 때만)           │
```

카드는 입력 패널 하나만 쓴다. 결과를 또 카드에 넣으면 모든 걸 똑같은 둥근 상자로 쪼개는 흔한 구성이 되고, 하늘 위에 바로 놓아야 콘셉트가 산다. 나머지 블록은 1px `--line` 구분선으로만 나눈다. 모서리는 위계별로 다르게: 입력칸 8px, 입력 패널 14px, 배지와 해 마커는 원.

번호 배지는 지름 24px, 1.5px `--accent` 테두리, 안은 비움, 숫자는 Barlow 600. 레퍼런스의 입체 구가 아니라 평면 외곽선이고, 입력 패널 안에서 왼쪽 정렬로만 쓴다.

**모바일 첫 화면 문제:** 320px에서는 입력 4개 때문에 결과가 화면 아래로 밀린다. 위치를 고른 뒤부터 화면 하단에 높이 56px짜리 고정 바로 "본전까지 약 7~12년"만 띄우고, 누르면 결과 영역으로 스크롤한다. 결과 영역이 화면에 들어오면 바를 숨긴다.

## 5. 적용한 디자인 원칙 (일반 원칙을 이 사이트에 맞게)

**선택지를 줄인다.** 고를 게 많을수록 결정이 느려진다. 첫 화면 입력은 4개로 제한하고, 방향·그늘은 접어두고 "모름"을 기본값으로 둔다.

**답은 스크롤 전에.** 사용자가 온 이유는 "몇 년이면 본전"이다. 데스크톱은 첫 화면에 결과가 보이고, 모바일은 4장의 고정 바로 해결한다.

**모바일부터.** 320px 기준으로 먼저 맞추고 넓힌다. 가로 스크롤 0.

**색에 의미를 혼자 지우지 않는다.** 잉여 구간은 색과 빗금을 같이, 범위는 띠와 숫자를 같이 보여준다.

**모두가 쓸 수 있게.** 2장의 대비 기준, 키보드 포커스 링(2px `--accent`, 2px 간격), `prefers-reduced-motion` 존중, 슬라이더는 숫자 입력과 동기화해서 키보드로도 조작.

## 6. 그래프

### 6.1 지평선 차트 (핵심, 1개만 크게)

- x축: 0~25년, 눈금은 0·5·10·15·20·25만. y축: 원, 눈금 없이 설치비 값만 표시.
- **지평선:** 설치비(보조금 뺀 금액) 높이의 가로선, 1px `--text`, 오른쪽 끝에 "설치비 525만 원" 라벨.
- **누적 절감선:** 원점에서 시작하는 2px `--accent` 직선(중앙 시나리오).
- **범위 띠:** 낮음~높음 시나리오 사이를 `--muted` 30% 불투명도로 채움.
- **해:** 중앙선이 지평선과 만나는 점에 지름 12px `--accent` 원 + 바깥에 같은 색 20%·10% 불투명도 고리 두 개(빛 번짐). 레퍼런스의 구 그라데이션은 쓰지 않는다.
- 해 바로 위에 "약 7년" 라벨(Barlow 600, 20px). 지평선 아래 영역은 `--text` 4% 불투명도로 아주 옅게 깔아 "아직 본전 전" 구간임을 표시.
- SVG 직접 작성, 높이 200px(모바일 160px). 라이브러리 없음.

### 6.2 월별 발전량과 사용량

- 막대 12개 `--accent`, 사용량은 1.5px `--text-2` 점선 가로선.
- 사용량을 넘는 막대 윗부분(이월되는 잉여)은 같은 색 45도 빗금으로 바꿔 색 없이도 구분되게.
- 막대 위 숫자는 최댓값과 최솟값 달에만 표시.

### 6.3 나중에 (v1.1)

패널 장수별 손익분기 곡선. 적정 장수에서 바닥을 찍는 곡선이라, 잉여 경고의 "5장이면 충분"을 그래프로 보여준다.

## 7. 아이콘·질감·움직임

**아이콘:** 레퍼런스처럼 얇은 선 스타일이되, 원본 그림이 아니라 오픈 라이선스 세트(Lucide, ISC 라이선스)에서 가져온다. 선 두께 1.5px, 크기 20px. **기능이 있는 곳에만** 쓴다: 검색 돋보기, 접힘 화살표, 잉여 경고. 장식용 아이콘은 넣지 않는다.

**질감:** 다크 모드에서만, 화면 위쪽 30% 구간에 별 10개 안팎을 CSS `radial-gradient`로 찍는다. 크기 1~2px, 불투명도 0.25 이하, 정지 상태. 레퍼런스의 아래쪽 보케 점과 반대로, 밤하늘 콘셉트에 맞춰 위쪽에만 둔다. 거슬리면 빼도 콘셉트는 유지된다.

**움직임:** 딱 한 번만. 위치를 처음 골라 결과가 처음 나올 때, 해 마커가 누적 절감선을 따라 지평선까지 올라간다(400ms, ease-out). 이후 입력이 바뀔 때는 숫자와 선이 150ms 페이드로만 바뀌고, 숫자가 올라가는 카운트업은 쓰지 않는다. `prefers-reduced-motion: reduce`면 이 움직임도 없이 바로 표시한다. 그림자는 해 마커의 빛 번짐 말고는 쓰지 않는다.

## 8. 문구

- 결과 표 머리글은 "발전량" "절감액". '수익'이라는 말은 쓰지 않는다.
- 손익분기는 "약 7~12년이면 본전"처럼 범위가 먼저, 중앙값(9.0년, 3,268일)은 작게.
- 잉여 경고: "매년 약 500kWh는 쌓이기만 하고 돈이 안 돼요. 5장으로 줄여도 절감액은 거의 같아요." 버튼은 "5장으로 바꿔 보기".
- 빈 상태: 위치 고르기 전에는 결과 자리에 "지역을 고르면 바로 계산해요" 한 줄.
- 오류: "이 지역은 일사량 데이터가 없어요. 가까운 시군구로 골라 주세요." 사과하지 않고, 무엇이 문제고 어떻게 하면 되는지만.
